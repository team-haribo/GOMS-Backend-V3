# GOMS PR Body Guidelines

Keep the order of `관련 이슈` (Related issues), `작업내용` (Changes), `참고사항` (Notes), and `PR 체크리스트` (PR checklist) from the current `.github/pull_request_template.md`. Do not change the existing heading and checklist text, and do not add headings that are not in the template by default.

- Issue being resolved: `Closes #<issue-number>`
- Merely related Issue: `Related to #<issue-number>`
- `작업내용`: briefly write only the key changes needed for review
- `참고사항`: write only operational impact, compatibility, important constraints, and actual verification results
- Do not check or record in the body any verification that was not run

Follow `AGENTS.md` for detailed metadata rules and `.agents/skills/write-pr/SKILL.md` for the writing procedure.
